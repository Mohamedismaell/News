A modern, high-performance News Application built with Flutter following **Clean Architecture** principles. The app provides a seamless browsing experience for the latest headlines across various categories, featuring localized caching, state preservation, and a premium UI/UX design.

---

## ✨ Features

- Interactive Onboarding:** smooth introduction with animated carousel.
- Smart Home Screen:** dynamic greeting and top headlines sections.
- Advanced Search:** real-time news search with history preservation.
- Categorized Browsing:** discover news by topics (Politics, Sports, Tech, etc.).
- Bookmarks System:** save your favorite articles for offline reading.
- User Profile:** customize your profile with local image persistence.
- Offline Support:** powered by Hive for robust local caching.
- Connection Awareness:** real-time internet connectivity monitoring with UI feedback.
- Clean Design:** Premium SF Pro typography and custom design tokens.

---

## 📂 Project Structure

The project follows the **Clean Architecture** pattern to ensure scalability, maintainability, and testability.

```text
lib/
├── core/                       # Shared logic across all features
│   ├── connection/             # Network connectivity handlers
│   ├── database/               # Hive & local cache configuration
│   ├── enums/                  # Global enums
│   ├── shared/                 # Shared widgets, domain entities, and logic
│   ├── theme/                  # Theme extensions and color palettes
│   └── util/                   # Common utility functions
├── features/                   # Feature-specific modules
│   ├── onboarding/             # Splash & Onboarding flow
│   ├── home/                   # Main news feed & Search
│   ├── categories/             # News by category
│   ├── book_marks/             # Saved articles
│   ├── profile/                # User settings & profile management
│   └── post_details/           # Detailed article view
├── hive_registrar.g.dart       # Autogenerated Hive registrar
└── main.dart                   # Application entry point
```

### Standard Feature Substructure

Each feature is divided into:

- **Data:** Data Sources (Remote/Local), Repositories Implementation, and Data Models (Mappers/DTOs).
- **Domain:** Entities, Repository Interfaces, and Use Cases.
- **Presentation:** Cubits (State Management), Screens, and Widgets.
- **DI:** Feature-specific Dependency Injection modules.

## 🧑‍💻 Tech Stack & Key Libraries

- **State Management:** [Flutter Bloc](https://pub.dev/packages/flutter_bloc) & [Bloc](https://pub.dev/packages/bloc)
- **Navigation:** [GoRouter](https://pub.dev/packages/go_router) (utilizing `StatefulShellRoute` for tab state preservation)
- **Dependency Injection:** [Get It](https://pub.dev/packages/get_it)
- **Database (Local):** [Hive CE](https://pub.dev/packages/hive_ce_flutter)
- **Networking:** [Dio](https://pub.dev/packages/dio)
- **UI & UX:**
  - `flutter_screenutil` (Responsive design)
  - `skeletonizer` & `shimmer` (Loading states)
  - `lottie` (Vector animations)
  - `carousel_slider` (Smooth sliders)
- **Persistence:** `path_provider`, `shared_preferences`

## 💨 Getting Started

### Prerequisites

- Flutter SDK (>= 3.2.0)
- Android Studio / VS Code
- A valid [NewsAPI](https://newsapi.org/) token

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Mohamedismaell/News_App.git
   ```

2. **Install dependencies:**

   ```bash
   flutter pub get
   ```

3. **Set up your API Key:**
   Navigate to `lib/core/database/api/end_points.dart` and add your token:

   ```dart
   static String token = 'YOUR_NEWS_API_TOKEN_HERE';
   ```

4. **Run build_runner** (if needed for code generation):

   ```bash
   dart run build_runner build --delete-conflicting-outputs
   ```

5. **Run the application:**
   ```bash
   flutter run
   ```
